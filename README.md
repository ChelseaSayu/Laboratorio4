9. ¿El comportamiento de los flujos de control es similar a otros lenguajes y ambientes de desarrollo?
Respuesta: Sí, en JavaScript el switch funciona casi igual que en otros lenguajes. La diferencia está en que aquí no solo compara valores constantes, sino que también puede evaluar expresiones y trabajar con distintos tipos de datos.
